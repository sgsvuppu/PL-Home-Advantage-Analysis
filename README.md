# Premier League Home Advantage Analysis
### Amazon/C1 Data Analytics Portfolio Project — 2026

## Research Question
Does home advantage still exist in the modern Premier League, 
and which match statistics best predict outcomes?

## Key Findings
- Home teams win 45.8% of matches vs 31.7% for away teams
- Shots on target is the strongest predictor (r = +0.42 / -0.46)
- Home advantage is consistent across all 3 seasons (2021-24)
- Man City win 80.7% of home games; Sheffield United only 10.5%

## Dataset
- Source: football-data.co.uk
- 1,140 matches across 3 Premier League seasons (2021-22, 2022-23, 2023-24)
- 22 analytical variables
